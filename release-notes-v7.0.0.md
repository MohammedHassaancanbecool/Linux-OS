# Drakonis Linux 7.0.0

Drakonis Linux 7.0 is the GNOME-based evolution of the 6.0 engineering baseline.

## Highlights

- Debian Stable amd64 live ISO with GNOME Shell and GDM3.
- DRAKONIS-Night and DRAKONIS-Carbon themes applied through GNOME settings.
- Rights-cleared indigo/cyan/violet wallpaper and login artwork.
- Centered Plank dock with GNOME Overview and four workspaces.
- Drakonis Control Center adapted for GNOME commands and applications.
- Debian-native, authorized defensive-analysis profiles with safe-by-default networking.
- No Kali or BlackArch repository mixing, credential theft, persistence, evasion, payload delivery, or automatic target activity.

## Known validation boundary

The source checks and ISO artifact checksum are automated. Complete GDM3/GNOME visual acceptance, installation testing, and hardware compatibility still require a graphical VM or physical x86_64 test host.
