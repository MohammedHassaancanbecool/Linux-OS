# Design reference

`kali-xfce-complete-design-book.pdf` is the 32-page visual reference supplied for the Drakonis Linux XFCE desktop implementation. It contains 29 visual concepts covering the desktop, Applications menu, terminal, file manager, login/lock screens, network tools, notifications, power/session, security center, settings, software center, system monitor, themes, browser, first-run, help, and workspace overview.

The images are treated as visual references only. Drakonis Linux keeps its own name, dragon mark, colors, artwork, and product identity; it does not redistribute or imitate third-party distribution branding.
