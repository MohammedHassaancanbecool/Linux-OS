# Drakonis Linux v0.5.0

## Highlights

- Added the supplied Drakonis login artwork to LightDM.
- Added QEMU x86, QEMU utilities, QEMU GUI support, and OVMF packages.
- Added a QEMU launcher that automatically selects KVM when `/dev/kvm` is available and falls back to one-CPU TCG compatibility mode otherwise.
- Added the Drakonis XFCE desktop shell autostart.
- Added a Plank dock with Control Center, file manager, terminal, browser, and Vault launchers.
- Kept the XFCE compatibility panel and existing Control Center so the desktop remains usable on conservative hardware.
- Preserved Debian-only package provenance and the authorized-use safety boundary.

## Validation

- Project checks passed.
- ISO SHA-256 verification passed.
- ISO contains BIOS and UEFI El Torito entries.
- QEMU BIOS smoke test reached ISOLINUX 6.04 in TCG mode; this environment has no `/dev/kvm`, so a complete accelerated graphical-session test requires a KVM-capable host.

## Known limitation

The supplied login artwork is used exactly as the LightDM background. LightDM GTK controls the interactive field geometry; exact pixel-level interactive matching would require a separate custom greeter implementation.
