# Drakonis Linux v0.4.0 development scope

Version 0.4.0 remains an XFCE edition. It improves the visual control-center shell and turns the previously generic destinations into operational first-pass pages for monitoring, notifications, workspaces, settings, and software profiles.

Drakonis Vault now supports verified HTML reports and optional AES-256-CBC encryption through OpenSSL with PBKDF2. The software center exposes profile listing and package lookup/install through configured Debian repositories only. The red-team boundary remains unchanged: no third-party APT repositories, automatic target discovery, persistence, evasion, credential theft, or payload delivery are added.

The automated validation covers shell syntax, Python compilation, project completeness, Git whitespace, Vault case creation, evidence addition, SHA-256 verification, and HTML report generation. A full GUI and hardware matrix still requires a VM or physical host with a working graphical session.
